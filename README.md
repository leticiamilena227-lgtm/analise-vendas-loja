# Análise de Vendas de uma Loja

## 📊 Sobre o projeto

Este projeto tem como objetivo analisar dados fictícios de vendas de uma loja utilizando **SQL e Python**.

A análise busca identificar padrões de vendas e gerar informações que podem auxiliar na compreensão do desempenho da loja.

## 🎯 Objetivos

- Calcular o faturamento total;
- Analisar o faturamento por produto;
- Analisar o faturamento por cidade;
- Analisar o faturamento por categoria;
- Identificar os produtos mais vendidos;
- Calcular o ticket médio;
- Analisar o faturamento ao longo dos meses.

## 🛠️ Tecnologias utilizadas

- Python
- SQL
- SQLite
- Pandas
- Matplotlib
- Google Colab

## 🔎 Principais análises

O projeto utiliza consultas SQL para realizar análises como:

- `SELECT`
- `WHERE`
- `JOIN`
- `GROUP BY`
- `ORDER BY`
- `SUM()`
- `AVG()`

Os dados também são organizados e visualizados utilizando **Pandas e Matplotlib**.

## 📈 Principais resultados

A análise identificou:

- Faturamento total de **R$ 12.540,00**;
- Ticket médio de **R$ 836,00**;
- **Eletrônicos** como categoria de maior faturamento;
- **Notebook** como produto de maior faturamento;
- **Mouse** como produto com maior quantidade de unidades vendidas;
- **São Paulo** como cidade com maior faturamento.

## 💡 Insight

Um dos principais insights foi perceber que o produto com maior quantidade de unidades vendidas não foi necessariamente o produto com maior faturamento.

O **Mouse** vendeu mais unidades, enquanto o **Notebook** gerou o maior faturamento.

## 📌 Observação

Os dados utilizados neste projeto são **fictícios** e foram criados exclusivamente para fins de estudo e portfólio.
